# ウマ娘レース計算機

ゲーム「ウマ娘プリティーダービー」のステータスやレース数値を計算できるPWAアプリです。

## 機能

- ステータス計算（バ場・コース・脚質適性補正）
- 速度計算（フェーズ別目標速度、ラストスパート速度、乱数範囲）
- HP・スタミナ計算（消費量、スキル発動率、持久力温存確率）
- 加速度計算（フェーズ別、スタートダッシュ、減速度）
- 特殊システム（掛かり確率、スタミナ勝負、全開スパート）
- コース補正ステータス対応

## 使い方

以下のURLからブラウザで直接利用できます（インストール不要）。

**https://pittua.github.io/umamusume_race_calculator/**

スマートフォンの「ホーム画面に追加」からPWAとしてインストールすることもできます。

## 注意事項

> **本アプリは現在仮実装です。**
> 表示される計算結果はあくまで参考値であり、実際のゲーム内の数値と異なる場合があります。
> 計算式やパラメータに誤りが含まれている可能性があるため、結果を過信せずご利用ください。
